2. Zweck der Anwendung

Die TOS Livestream Automation ist ein lokales Automatisierungswerkzeug. Sie erstellt und verwaltet geplante YouTube-Livestreams (Live-Broadcasts, Live-Streams, Thumbnails, Live-Chat-Einstellungen) auf den eigenen YouTube-Kanälen des Betreibers und schreibt die erzeugten Video-IDs in eine eigene Google-Sheets-Tabelle. Die Anwendung wird ausschließlich vom Betreiber selbst genutzt.

3. Welche Google-Nutzerdaten werden verarbeitet?

Die Anwendung greift über die Google-APIs ausschließlich auf Daten der eigenen Konten zu:

  • YouTube Data API v3 (Scopes youtube.force-ssl, youtube.upload): Kanal-Informationen des eigenen Kanals, Erstellung und Verwaltung von Live-Broadcasts und Live-Streams, Upload von Thumbnail-Bildern
  • Google Sheets API (Scope spreadsheets): Lese- und Schreibzugriff auf eine einzelne, vom Betreiber festgelegte Tabelle (Speicherung von Video-IDs und Sendezeiten)

Es werden keine Daten anderer Google-Nutzer erhoben, gelesen oder gespeichert.

4. Speicherung und Aufbewahrung

Sämtliche Verarbeitung erfolgt lokal auf dem Rechner des Betreibers. Die Anwendung betreibt keinen Server und überträgt keine Daten an Dritte. Im Einzelnen werden lokal gespeichert:

  • OAuth-Zugriffs- und Refresh-Tokens (token.json, token_secondary.json) zur Anmeldung bei den Google-APIs
  • Lokale Excel-Dateien mit Sendeplanung und Video-IDs
  • Lokale Protokolldateien (Logs) zur Fehleranalyse

Eine Weitergabe, der Verkauf oder die Nutzung der Daten für Werbung oder andere Zwecke findet nicht statt.

5. Einhaltung der Google API Services User Data Policy

Die Nutzung der über Google-APIs erhaltenen Informationen durch diese Anwendung erfolgt in Übereinstimmung mit der Google API Services User Data Policy einschließlich der Anforderungen der eingeschränkten Nutzung (Limited Use):

  • Daten werden nur für den beschriebenen Zweck (Planung eigener Livestreams) verwendet
  • Keine Übertragung an Dritte, keine Nutzung für Werbung, kein Profiling
  • Keine Einsichtnahme durch Menschen, außer zur Fehlerbehebung durch den Betreiber selbst

6. Widerruf und Löschung

Du kannst der Anwendung den Zugriff jederzeit entziehen:

  • In den Google-Kontoeinstellungen unter myaccount.google.com/permissions den Zugriff der App widerrufen
  • Die lokalen Token-Dateien (token.json, token_secondary.json) löschen – danach besitzt die Anwendung keinen Zugriff mehr

Da alle Daten ausschließlich lokal gespeichert werden, ist mit dem Löschen der lokalen Dateien sämtliche gespeicherte Information entfernt.

7. Keine Cookies, kein Tracking

Diese Website und die Anwendung verwenden keine Cookies, keine Analyse-Werkzeuge (z. B. Google Analytics) und keinerlei Tracking-Technologien.
